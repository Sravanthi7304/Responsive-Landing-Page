# 🚀 Responsive Landing Page

A modern, fully responsive landing page built as part of **Prodigy InfoTech Web Development Internship - Task 01**.

![Landing Page Screenshot](screenshot.png)

## 📌 About The Project
This project is a clean and modern landing page designed to work perfectly on all devices - desktop, tablet, and mobile. It uses only HTML, CSS, and JavaScript to create a fast and interactive user experience.

The goal was to practice responsive web design, smooth navigation, and modern UI trends like glassmorphism and animations.

## ✨ Features
- **Fully Responsive** - Works on all screen sizes using Flexbox and Media Queries
- **Sticky Navbar** - Changes background on scroll with blur effect
- **Smooth Scrolling** - Smooth navigation between sections
- **Modern UI** - Gradient background, hover animations, and clean typography
- **Mobile Menu** - Hamburger menu for mobile devices
- **Lightweight** - No frameworks used. Pure HTML, CSS, and JS

## 🛠️ Tech Stack
- **HTML5** - Page Structure
- **CSS3** - Styling, Animations, Responsive Design  
- **JavaScript** - Interactivity and Scroll Effects
